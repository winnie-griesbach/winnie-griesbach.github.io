# Winnie Griesbach — E-Commerce Portfolio

Static portfolio for GitHub Pages, built with **HTML, CSS, JavaScript, Jekyll/Liquid and JSON**.

## Files
- `index.html` — Jekyll/Liquid page structure
- `_config.yml` — GitHub Pages/Jekyll site settings
- `_data/journey.yml` — customer-journey case-study steps
- `assets/data/work-evidence.json` — public-safe English recruiter evidence
- `assets/css/styles.css` — visual system and responsive layout
- `assets/js/script.js` — filters, search, evidence rendering and reveal animation

## Publish
Upload the contents of this folder to the root of `winnie-griesbach.github.io`. GitHub Pages will rebuild automatically.

## Important
This package intentionally contains **no raw internal workbooks, private analytics exports or confidential source data**. Only recruiter-safe summaries are included.
