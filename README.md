# Winnie Griesbach – E-Commerce Portfolio (V3)

Static portfolio for GitHub Pages, built with **HTML, CSS, JavaScript, Jekyll/Liquid and JSON**.

## Included structure

- `index.html` — main page
- `_config.yml` — GitHub Pages / Jekyll settings
- `_data/journey.yml` — compact case-study steps
- `assets/data/work-evidence.json` — recruiter-safe evidence entries
- `assets/css/styles.css` — design system and responsive layout
- `assets/js/script.js` — filtering, search and reveal behavior
- `assets/media/*` — photos, product visuals, posters and videos

## What changed in V3

- removed the duplicated click-navigation in the hero area
- added a profile card with LinkedIn-style banner and personal details
- added one single section navigator under the hero
- added an interface-principle banner
- made the case-study steps more compact
- moved the videos into a dedicated visible showcase
- reduced the visual weight of the product examples
- fixed the evidence filter script

## Publish on GitHub Pages

Upload the full folder structure into the repository root `winnie-griesbach.github.io`.
GitHub Pages should rebuild automatically.
