Product / tool demos

See the tools in motion.

Short product videos showing how I turned complex fence planning into clearer, more guided user flows. The shop interface is German; the context below explains what each tool is designed to achieve.

Price Check

A lightweight pre-configurator that helps users estimate fence length, material choice and starting cost before entering the full buying flow.

Goal: reduce uncertainty early and give users a clear starting point.

Fence Configurator

A guided configuration flow that translates project inputs into a structured setup, helping users move from planning to cart with less friction.

Goal: simplify decision-making and turn planning into action.

Privacy Strip Configurator

A visual tool for configuring privacy strips, helping users choose style, structure and matching components more intuitively.

Goal: make a visual and customizable product easier to understand.
